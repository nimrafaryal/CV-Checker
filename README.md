# CV Checker

A machine learning / AI-based CV screening system that analyzes resumes and helps evaluate candidate suitability.

## Features

- Resume parsing
- Skill extraction
- Candidate evaluation
- Automated screening

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-Learn

## Project Structure

- CV_checker.ipynb : Main notebook
- requirements.txt : Dependencies

## Future Improvements

- Web interface
- Advanced NLP models
- PDF resume processing
